Land Price Prediction System

📌 Overview:
The Land Price Prediction System is an AI-powered Business Intelligence application designed to estimate land prices across Tamil Nadu using predictive analytics and data-driven techniques.

The system analyzes factors such as:
- District
- Area Type
- Road Facility
- Distance to Schools
- Distance to Hospitals
- Distance to Bus Stands
- Distance to Airports
- It also provides investment analysis and interactive Business Intelligence dashboards for better real estate decision-making.

🚀 Features:
- AI-based land price prediction
- Business Intelligence dashboard
- Investment classification
- Real-time analytics
- District-wise price comparison
- Infrastructure impact analysis
- Interactive charts and graphs
- Responsive web interface
